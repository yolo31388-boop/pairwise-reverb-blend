# pairwise-reverb-blend

推门进山洞，脚步声的尾音在门口被硬切一半，退回走廊又整段消失：混响区按包围盒触发，角色跨边界时没有交叉淡入；室内外混响总线共用一套参数，出门后尾音还挂在洞里；卷积混响的 IR 按采样率加载，设备切换后时长错；混响发送量按距离线性，门口和洞底一样响；多个混响区重叠时直接相加，音量爆掉；尾音在暂停/切歌时没有 flush，下一段音频带着旧尾音；空间音频的 HRTF 在混响前做，声像被尾音拉宽；混响区跟随相机而不是听者，第一人称转身时尾音方向错；异步加载 IR 时用占位脉冲，加载完成前听到咔哒；混响与遮挡共用一套低通，墙后声音被过度闷住；音频线程和游戏线程各算一次区域权重，切换时跳变；混响缓存按场景 ID，切画质后仍用旧 IR；多人语音共用混响总线，队友语音被山洞尾音糊住。audio/reverb_zone.py 是核心，tests/test_reverb_zone.py 15个红。要修的是：边界交叉淡入；内外总线；采样率 IR；距离曲线；重叠归一；尾音 flush；HRTF 顺序；听者位置；异步占位；遮挡分离；线程一致；缓存版本；语音隔离。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
